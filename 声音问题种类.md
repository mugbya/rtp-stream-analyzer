| 类别      | 用户常说/听感词    | 对应工程术语                                     | 常见原因/先查方向                  | 验证方法/工具        |
| :-------- | :----------------- | :----------------------------------------------- | :--------------------------------- | :------------------- |
| 无声/连通 | 通话建立但没声音   | No audio after connect                           | 权限、静音、音频焦点、路由、采样率 | 查权限/静音/路由日志 |
| 无声/连通 | 媒体正常，通话没声 | Call-path audio failure                          | HFP/SCO、AudioSession、路由        | 切 A2DP/外放对比     |
| 无声/连通 | 录音正常，通话没声 | Capture OK but no call audio                     | 3A、编码、上行 RTP                 | 本地录音 + RTP 抓包  |
| 无声/连通 | 我听不到对方       | Downlink one-way audio                           | 下行、播放设备、路由、网络         | 看下行 RTP、换耳机   |
| 无声/连通 | 对方听不到我       | Uplink one-way audio                             | 麦克风、权限、上行、NAT            | 看上行 RTP、换麦克风 |
| 音量      | 对方说我声音小     | Uplink low level                                 | 麦克风增益、遮挡、AGC              | 录音自测、电平表     |
| 音量      | 我听对方声音小     | Downlink low volume                              | 扬声器、路由、单侧                 | 换耳机、看音量       |
| 音量      | 忽大忽小           | AGC pumping / Level fluctuation                  | AGC、VAD、网络抖动                 | 关 AGC 对比          |
| 噪声      | 风噪               | Wind noise                                       | 风、麦克风位置、ANS                | 户外/遮挡测试        |
| 噪声      | 键盘、敲击声       | Transient noise                                  | ANS 不足、瞬态噪声                 | 打字测试             |
| 噪声      | 呼吸声、喷麦       | Plosive / Pop                                    | 近讲、防喷罩、HPF                  | 近讲测试             |
| 噪声      | 齿音刺耳           | Sibilance                                        | 高频增益、EQ                       | 录齿音对比           |
| 噪声      | 滋滋电流声         | Buzz / Ground loop                               | 电源、USB、接地                    | 换电源/换 USB        |
| 失真      | 水声、闷           | Underwater / Muffled                             | 低通、窄带、丢包、蓝牙 HFP         | 查采样率/编解码      |
| 失真      | 电音、机关枪       | Codec artifact / PLC                             | 丢包、PLC、低码率                  | 抓包看丢包           |
| 失真      | 炸麦、破音         | Clipping / Overload                              | 增益过高、削波                     | 看电平表             |
| 断续      | 爆音后静音         | PLC / Concealment artifact                       | 丢包、抖动、缓冲欠载               | RTP/RTCP 统计        |
| 断续      | 一动就断           | Intermittent / Contact issue                     | 耳机插头、蓝牙、线材               | 摇动测试、换线       |
| 回声      | 听到自己延迟       | Sidetone / Echo                                  | 侧音、AEC、路由                    | 关侧音/AEC 对比      |
| 双讲      | 我一说对方就断     | Double-talk suppression / Half-duplex            | AEC、降噪、VAD                     | 双讲测试             |
| 算法      | 吞字、丢字         | VAD misdetect / NS over-suppression              | VAD、降噪、AEC、丢包               | 关 3A 对比           |
| 设备      | 蓝牙像打电话       | Bluetooth HFP/SCO narrowband                     | HFP/SCO、mSBC                      | 切 A2DP 对比         |
| 设备      | 免提/外放回音啸叫  | Speakerphone feedback/echo                       | AEC、麦距、增益                    | 外放测试             |
| 网络      | 延迟大             | Latency / Mouth-to-ear delay                     | 网络、缓冲、编解码、蓝牙           | RTT/jitter 统计      |
| 协议      | 变调、忽快忽慢     | Pitch shift / Clock drift / Sample rate mismatch | 采样率、时钟、重采样               | 查采样率/时钟        |
| 平台      | 特定 App 异常      | App audio session/route issue                    | 音频焦点、权限、SDK                | 换 App 对比          |





优先级可以这样分：

- **P0**：无声、单通、通话建立失败
- **P1**：啸叫、严重回声、严重断续、双讲断
- **P2**：音量小、噪声、发闷、机器人音
- **P3**：轻微音质、齿音、轻微底噪
